Insights / data

Selective-college acceptance rates, with sources

The homepage chart summarizes a decade of compression at eight highly selective schools. This page is the citeable record: first-time, first-year applicant and admit counts from each school's own Common Data Set, fact book, or admissions fact sheet. Retrieved 11 September 2026. No third-party aggregator is used as a source.

Last retrieved: 11 September 2026

01/03Method

What is being compared

Acceptance rate here is admitted first-time, first-year students divided by first-time, first-year applicants, using the school's published counts. Rates in the table are calculated from those counts and rounded to one decimal place.

  • Prefer Common Data Set item C1 for the fall census named on the filing (CDS 2015-16 = Fall 2015 entering class, and so on).
  • Where a school publishes an official class-year series or admissions fact sheet that is more current, or where the live CDS file was not retrievable, that institutional page is cited instead and labeled.
  • Relative change is (baseline rate − recent rate) / baseline rate. The unweighted mean of those eight relative changes is 41.5%.
  • The homepage keeps its existing rounded figures, including the “~45%” summary. Some homepage “recent” cells are an earlier cycle than the latest official release below. This page does not change those homepage numbers.

03/03Sources

Dated institutional publications

Each row links the exact publication used. Retrieval date for every source is 11 September 2026 unless noted.

Harvard College

Office of Institutional Research & Analytics, Fact Book: College Admissions, last updated 7 January 2026. Class of 2020: 39,041 applicants, 2,110 admitted (5.4%). Class of 2026: 61,221 / 1,984 (3.2%). Class of 2029: 47,893 / 2,003 (4.2%). The Fact Book class-year series is what the homepage 5.4% → 3.2–4.2% range follows. CDS filings are indexed at Harvard Common Data Set.

Stanford University

Institutional Research & Decision Support, Stanford Common Data Set. CDS 2015-16 C1: 22,831 men + 19,666 women applied (42,497); 1,073 + 1,067 admitted (2,140). CDS 2024-25 C1: 29,602 + 27,724 applied (57,326); 1,015 + 1,052 admitted (2,067). Files are the official Drive links published on that IR&DS page.

University of Pennsylvania

Baseline: Annual Financial Report, Fiscal Year 2015 — 37,268 applications and 3,787 admitted for the freshman class entering fall 2015. Recent: University of Pennsylvania, Facts, Undergraduate Admissions (Fall 2025) — 72,544 applications and 3,570 offered admission to the Class of 2029. Penn rounds that recent rate to “5 percent”; 3,570 / 72,544 is 4.9%. CDS PDFs are listed at Penn IRA Common Data Set (Box downloads; the counts above are taken from the public HTML/PDF pages, not from a third-party summary).

Williams College

Baseline: Williams College Common Data Set 2016-2017 C1 (Fall 2016): 3,313 + 3,672 applied (6,985); 601 + 629 admitted (1,230). The live IR host returned HTTP 403 from this research environment; the same official PDF was read via the Internet Archive copy of that Williams URL. Recent: Office of Communications, Fast Facts About Williams, April 2026, Class of 2029 — 15,520 applied, 1,336 admitted, 8.6%. The homepage 10.0% recent figure is an earlier cycle than this Fast Facts release.

Amherst College

CDS section C, published on Amherst's Common Data Sets index. 2015-16 C. First-Year Admission: 3,882 + 4,686 applied (8,568); 583 + 627 admitted (1,210). 2025-26 C. First-Time, First-Year Admission: 15,819 applied and 1,222 admitted (residency totals on the same page). Amherst's 2024-25 C section reports 13,743 applied and 1,238 admitted (9.0%), which is the homepage recent cell; the table uses the newer 2025-26 filing. Index: Amherst Common Data Sets.

Swarthmore College

Baseline: Swarthmore CDS 2015-2016 C1, from the college's institutional-research PDF (Internet Archive copy of the official file): 3,365 + 4,453 applied (7,818); 470 + 506 admitted (976), labeled 12.5% on the filing. Recent: Swarthmore Admissions, Class of 2029 fact sheet (May 2025) — 12,995 applied, 965 admitted, 7.43%. CDS archive: Swarthmore Common Data Set. The homepage 6.9% recent figure is an earlier cycle than this fact sheet.

Middlebury College

CDS 2015-2016 C1: 3,702 + 5,189 applied (8,891); 741 + 810 admitted (1,551), 17% on the filing; 1,551 / 8,891 is 17.4%. CDS 2024-2025 C1: 12,540 applied, 1,348 admitted (1,348 / 12,540 = 10.75%, shown as 10.7%). Index: Middlebury Historical Data / Common Data Sets.

Bowdoin College

Office of Institutional Research, Analytics, and Consulting, Common Data Set. 2015-16 C1: 2,996 + 3,794 applied (6,790); 476 + 534 admitted (1,010). 2025-26 C1 form fields: 14,045 applied, 957 admitted. The homepage 6.8% recent figure matches this 2025-26 filing (Class of 2029).

This page documents published selectivity. It is not a prediction about any applicant, and it is not a claim that a Vellum seminar changes an admissions decision.
